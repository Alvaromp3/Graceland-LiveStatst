# Data Model

## Scope

**Team-level analytics only.** No player registry, roster, or individual player profiles.

## Core entities

- **Team**, **Game**
- **Event**, **BallTrack**, **Possession**
- **PlayerTrack** — anonymous blobs for collective metrics (heatmap, block height, width)
- **GameStatistics**, **ModelPrediction**
